# BU CS Foundations Bootcamp

This repository contains my work for the Boston University
Online AI Programs CS Foundations Bootcamp.

## Structure

- module1/ : Development environment and first Java programs
- module2/ : Programming fundamentals (variables, control flow, methods, files)
- module3/ : Data structures and object-oriented basics
- module4/ : Git, GitHub, and version control workflow
- module5/ : Problem solving and intermediate Java logic
- module6/ : More advanced programming concepts and practice

## Module 1

- Java setup and VS Code configuration
- Writing and running a first Java program

## Module 2

- Variables, operators, and input/output
- Conditions, loops, and basic logic
- Methods and reusable code

## Module 3

- Arrays and collections
- Object-oriented programming basics
- Working with classes and data

## Module 4

- Git and GitHub workflow
- Commits, branches, and pull requests

## Module 5

- Debugging and problem solving
- Intermediate Java logic
- Practice with more complex programs

## Module 6

- File handling and data processing
- More advanced programming concepts
- Applying logic to real tasks

## Programs

Each module folder contains the Java source files from that module’s activity.

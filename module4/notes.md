In Module 4, I learned how Git and GitHub help developers manage code changes, track progress, and collaborate effectively. I practiced creating branches, making commits, and using pull requests to review and merge work safely. I also learned how version control keeps a project organized and makes it easier to recover from mistakes while working on larger coding projects.

some git workflow commands

- git status: checks the state of the repository
- git add: stages changes to be committed
- git commit: saves staged changes with a message
- git push: uploads branch changes to GitHub
- git checkout main: switches back to the main branch
- git pull: updates the local branch with the latest remote changes
